# Qatar Family Court information portal

Static Arabic/English information portal for Qatar Family Court services, requirements, official resources, and a rule-based guidance widget.

## Local development

```bash
pnpm install
pnpm dev
```

## Quality checks

```bash
pnpm check
pnpm test
pnpm build
```

Pushing to `main` runs the GitHub Pages workflow in `.github/workflows/deploy-pages.yml`.
